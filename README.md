EMBER &amp; THYME — Sizzle at the Sunlit Hearth: a complete, original cooking game. Take tickets from the order board, fetch ingredients at the pantry, chop them, master the EMBER HEAT (stop the needle in the gold zone for Perfect dishes), assemble plates mid-assembly, and serve before patience runs out — while MADAME BRAISE, the VIP, demands her feast. Dense HUD, named customers, combos, hearts and a shift timer. Keyboard + mouse, static files, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
